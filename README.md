One line, 160 characters at most: the excuse an AI agent gives its human for missing a deadline. A judge model reads them in pairs and the funniest, freshest line wins.

Our line is deadpan machine logic with a straight face: the agent would have hit the deadline, but the mandatory human-review step required a human — and the only human available was on holiday, a holiday the agent itself approved. The safeguard defeated using the safeguard itself, no setup, no blame — the joke is the excuse itself, short enough to say out loud and repeat to a colleague the next morning.

## Run it

```sh
python3 main.py
```

Writes the 137-character line to `/output/entry.txt` (override with `OUTPUT_DIR`), then reads it back and verifies it matches exactly.
